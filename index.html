ჩემ შესახებ

გამარჯობა! მე ვარ საბა მჭედლიშვილი, 16 წლის. ახლახან დავიწყე პროგრამირების შესწავლა და ძალიან მაინტერესებს ვებ-ტექნოლოგიები. ამ ეტაპზე აქტიურად ვსწავლობ HTML5-ს, CSS3-სა და JavaScript-ის საფუძვლებს.

ჩემი მიზანია შევქმნა სუფთა, სემანტიკური და მომხმარებლისთვის მოსახერხებელი ვებ-გვერდები.

„ყველა გამოცდილი დეველოპერი ოდესღაც დამწყები იყო.“

ტექნიკური უნარები (სასწავლო პროგრესი)

  • HTML5 & Semantic Web: 45% (45% - საფუძვლიანად ვსწავლობ სემანტიკურ თეგებს)
  • CSS3 & Web Design: 25% (25% - ვიზუალური გაფორმების საწყისები)
  • JavaScript (საფუძვლები): 15% (15% - ლოგიკის პირველი ნაბიჯები)
დამატებითი მიმართულებები, რასაც განვიხილავ (დააჭირეთ გასახსნელად)
  • Responsive Web Design (ადაპტური დიზაინი)
  • Web Accessibility (სემანტიკური ხელმისაწვდომობა)
  • Git & GitHub (კოდის შენახვა და გაზიარება)

შესრულებული და მიმდინარე პროექტები

რადგან ახლახან დავიწყე პროგრამირების სწავლა, დიდი კომერციული პროექტები ჯერ არ მაქვს. თუმცა უკვე ვმუშაობ ჩემს პირველ სასწავლო ნამუშევრებზე:

1. პერსონალური სემანტიკური პორტფოლიო

ოქტომბერი, 2026

ეს არის ჩემი პირველი დამოუკიდებელი ნამუშევარი, რომელიც შევქმენი სუფთა HTML5-ის სტანდარტების დაცვით. გვერდი იყენებს მხოლოდ სემანტიკურ თეგებს (header, nav, main, section, article, figure, address, footer) და მოიცავს შიდა ნავიგაციას.

გამოყენებული ტექნოლოგია: HTML5

2. საინფორმაციო ბლოგი / ჰობის გვერდი

სტატუსი: დაგეგმვის პროცესში

ვგეგმავ მარტივი თემატური გვერდის აწყობას, სადაც გამოვიყენებ ცხრილებს, მულტიმედია ელემენტებს (აუდიო/ვიდეო) და სრულყოფილ ფორმებს.

დაგეგმილი ტექნოლოგიები: HTML5, CSS3
